# GitHub 배포 안내

초기 ZIP 제작 당시의 GitHub 접근 권한 문제는 사용자가 저장소 접근을 추가한 뒤 해결되었습니다. 초기 실습 자료와 Codex 인수인계 문서는 `feat/toy-model-lab`에서 `main`으로 들어가는 PR로 제공합니다.

현재 원격 상태 및 PR의 실제 검사 결과는 GitHub에서 확인하세요:
https://github.com/G-M-Kim/learning_AI_models/pulls

PR을 main에 반영하려면 Checks를 확인한 뒤 **Merge pull request** 또는 **Squash and merge**를 사용합니다. Approve 리뷰만으로는 merge되지 않습니다.

최초 clone 및 Python/GPU 설치: `docs/SETUP_WINDOWS.md`. 후속 수정 작업: `docs/CODEX_HANDOFF.md`.
